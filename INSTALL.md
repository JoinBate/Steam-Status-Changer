# 🎮 Steam Status Changer — Инструкция по установке и запуску

## 1. Установка Node.js

Скачайте и установите Node.js (рекомендуется LTS версия): [https://nodejs.org/](https://nodejs.org/)

После установки откройте **Командную строку (cmd)** или **PowerShell** и проверьте корректность установки:

```bash
node --version
npm --version
```
(Должны отобразиться установленные версии, например, v18.x.x и 9.x.x).

---

## 2. Установка зависимостей

Откройте терминал в папке с распакованным проектом и введите команду:

```bash
npm install

```

Эта команда автоматически скачает все необходимые библиотеки для работы программы (для взаимодействия со Steam и отрисовки интерфейса).

---

## 3. Запуск и Настройка

Вам **НЕ НУЖНО** вручную редактировать файлы с кодом или настройками.

Для пользователей **Windows** достаточно просто запустить файл `start.bat`.
Либо используйте команду в терминале:

```bash
node index.js

```

При запуске откроется интерактивное меню прямо в консоли, где вы сможете:

* Ввести логин и пароль от аккаунта Steam.
* Добавить список фраз для поочередного отображения в статусе.
* Настроить интервал смены фраз (в секундах).
* Включить или выключить «Умный АФК-режим».

Все введенные данные программа сама аккуратно сохранит в локальный файл `config.json`.

---

## 4. Авторизация и Steam Guard

При первом подключении скрипт запросит **код Steam Guard**:

* Код придет на почту (если включена почтовая защита).
* Либо сгенерируется в мобильном приложении Steam.

После успешного входа программа сохранит токен сессии. При следующих запусках пароль и код Steam Guard спрашиваться **не будут** — авторизация произойдет автоматически в фоновом режиме.

---

## 5. Остановка работы

Чтобы остановить скрипт, просто закройте окно терминала или нажмите `Ctrl + C`.

---

## 🛡️ Рекомендации по безопасности

1. **Никому не показывайте файл `config.json`!** В нём хранятся ваши логин и пароль от Steam. Обязательно убедитесь, что этот файл добавлен в `.gitignore`, если вы работаете с GitHub.
2. **Берегите файлы сессий.** Не передавайте третьим лицам файлы авторизации (например, `steam_session.json` или s-файлы), чтобы избежать перехвата аккаунта.
3. **Steam Guard обязателен.** Без него использование сторонних скриптов небезопасно. Двухфакторная аутентификация через телефон — лучший выбор.
4. **Управление сессией.** Если скрипт стал выдавать ошибки авторизации (токен устарел), вам не нужно искать и удалять системные файлы. Просто выберите пункт **«Сбросить сохранённую сессию Steam Guard»** в главном меню программы.
5. **Лимиты Steam.** Steam может временно заблокировать возможность менять статус при спаме запросами. Рекомендуем устанавливать интервал смены фраз **не менее 10–15 секунд**.
