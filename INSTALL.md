# Steam Status Changer — Инструкция по установке и запуску

## 1. Установка Node.js

Скачай и установи Node.js (LTS версию):
https://nodejs.org/

После установки открой **Командную строку (cmd)** или **PowerShell** и проверь:

```bash
node --version
npm --version
```

Должны отобразиться версии (например, v18.x.x и 9.x.x).

---

## 2. Установка зависимостей

Открой терминал в папке с проектом:

```bash
cd C:\Users\Admin\steam-status-changer
npm install
```

Эта команда скачает библиотеки `steam-user` и `steam-totp` (если понадобится).

---

## 3. Настройка конфига

Открой файл `config.json` и заполни:

- `username` — твой логин Steam
- `password` — твой пароль Steam
- `interval_seconds` — задержка между сменами статуса (в секундах)
- `phrases` — список фраз, которые будут поочерёдно отображаться

### Пример:

```json
{
    "account": {
        "username": "mylogin",
        "password": "mypassword123"
    },
    "settings": {
        "interval_seconds": 45,
        "phrases": [
            "🎮 Играю в Cyberpunk 2077",
            "💻 Пишу код"
        ]
    }
}
```

> ⚠️ **Никому не показывай этот файл** — в нём лежат логин и пароль!

---

## 4. Запуск

```bash
node index.js
```

При первом запуске скрипт запросит **код Steam Guard**:

- Код приходит на почту, если у тебя включена почтовая защита
- Или генерируется в приложении Steam Authenticator

После успешного входа сессия сохранится в файл `steam_session.json`. При следующих запусках код спрашиваться **не будет** (до тех пор, пока сессия не истечёт).

---

## 5. Остановка

Нажми `Ctrl + C` в терминале.

---

## Рекомендации по безопасности

1. **Не используй основной аккаунт** — создай отдельный Steam-аккаунт для тестов, если есть возможность.
2. **Не выкладывай config.json** в открытый доступ (GitHub, форумы и т.д.).
3. **Steam Guard обязателен** — без него аккаунт могут угнать. Двухфакторка (Steam Guard Mobile Authenticator) — самый безопасный вариант.
4. **Файлы `steam_session.json` и `steam_sentry.json`** тоже не свети — через них можно перехватить сессию.
5. Если скрипт перестал работать (ошибка `LoggedInElsewhere` или `InvalidPassword`), просто удали `steam_session.json` и запусти заново — введёшь код ещё раз.
6. Steam может временно забанить аккаунт за слишком частую смену статуса. Рекомендую ставить интервал **не меньше 15–30 секунд**.
