# 🎮 Steam Status Changer

![NodeJS](https://img.shields.io/badge/Node.js-43853D?style=for-the-badge&logo=node.js&logoColor=white)
![Steam](https://img.shields.io/badge/Steam-000000?style=for-the-badge&logo=steam&logoColor=white)

Красивая и мощная консольная утилита (CLI) для автоматической смены кастомного статуса (названия игры) в Steam.

## ✨ Особенности

*   🔄 **Цикличная смена статуса:** Укажите любые фразы, и программа будет поочередно транслировать их в ваш профиль через заданный интервал времени.
*   🧠 **Умный АФК-режим:** Скрипт может автоматически крутить фразы только тогда, когда в клиенте Steam установлен статус «Нет на месте» (Away). Не мешает запуску обычных игр!
*   🎨 **Стильный интерфейс:** Удобное интерактивное меню прямо в терминале с красивым градиентным дизайном. Больше не нужно копаться в коде для смены настроек.
*   🔒 **Сохранение сессии:** Логин и код Steam Guard запрашиваются только один раз. Токен сохраняется локально для быстрых последующих запусков.
*   🛡️ **Авто-восстановление:** Умная обработка ошибок (например, таймаутов серверов Steam) с автоматическим переподключением.

## 🚀 Как установить

1. Убедитесь, что у вас установлен [Node.js](https://nodejs.org/) (желательно версии LTS).
2. Скачайте этот репозиторий (кнопка `Code` -> `Download ZIP`) и распакуйте в любую папку.
3. Откройте терминал (или командную строку) в папке с проектом и установите нужные библиотеки командой:
```bash
   npm install

```

4. Переименуйте файл `config.example.json` в `config.json` (можно оставить его пустым, программа сама заполнит его при первом запуске через меню).

## 🕹️ Запуск

Для пользователей **Windows**: просто запустите файл `start.bat`.

Либо используйте команду в терминале:

```bash
node index.js

```

## ⚙️ Настройки

Все настройки (смена аккаунта, интервал, список фраз и режим АФК) управляются прямо из главного меню программы при её запуске. Вам не нужно вручную редактировать текстовые файлы.
