# Steam-Status-Changer
Переименуйте файл config.example.json в config.json (можно оставить его пустым, программа сама заполнит его при первом запуске через меню).

🕹️ Запуск
Для пользователей Windows: просто запустите файл start.bat.

Либо используйте команду в терминале:

⚙️ Настройки
Все настройки (смена аккаунта, интервал, список фраз и режим АФК) управляются прямо из главного меню программы при её запуске. Вам не нужно вручную редактировать текстовые файлы.
